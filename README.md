# LiveRoute
O LiveRoute é um chatbot interativo desenvolvido para a plataforma Telegram, projetado para transformar a experiência de quem visita ou mora em Belém do Pará. O bot atua como um guia digital, oferecendo roteiros personalizados para explorar as riquezas da capital paraense de forma prática e direta.

Funcionalidades
Interação Personalizada: O bot solicita e armazena informações básicas (como seu nome) para tornar o atendimento mais próximo.

Curadoria de Roteiros: Atualmente, o LiveRoute conta com duas trilhas principais:

Roteiro Gastronômico: Uma imersão nos sabores amazônicos, indicando os melhores pontos para provar o tacacá, o açaí original e outras iguarias locais.

Roteiro Histórico: Uma viagem no tempo por monumentos, casarões e pontos turísticos que contam a história de Belém.
